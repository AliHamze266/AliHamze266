## About me

M.Sc. Business Informatics student with a focus on Data Science, specializing in **machine learning and deep learning**. My work sits where machine learning meets real business data: messy inputs, few clean labels, and results that have to run in a real system, not only in a notebook. Passionate about data-driven decision making and the translator role between both sides: turning a business question into a working ML solution, and explaining the model's results back in business terms.

So far, my projects have covered three areas:

**Deep learning and computer vision at scale.** A cloud-native analytics platform on Microsoft Azure with Apache Spark for large-scale data processing and a deep learning component for multi-label image classification with CNNs (EfficientNet, PyTorch). The work involved transfer learning, weak labels derived from free text, a decision threshold tuned for the use case, and batch inference in the cloud instead of only in a notebook.

**NLP and generative AI on enterprise data.** An AI-powered chatbot for enterprise reporting that used NLP and text-to-SQL to give non-technical users access to company data in plain language, supported by prompt engineering for complex schemas and conversational context.

**IoT and real-time data visualization.** An IoT-based augmented reality application on the Meta Quest 3 that visualized live sensor data from MQTT and InfluxDB in real time, with room selection by voice.
